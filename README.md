# Kaak & Code - Café Website

A small student project for practicing HTML, CSS and JavaScript with a Lebanese café theme.

## Features
- A menu page for manoushe, kaak and drinks
- Navigation links to sections of the page
- Local images and a café logo
- JavaScript enhancements for page greetings and interactions
- External stylesheet for colors and layout

## Files
- `menu.html` - main website
- `style.css` - styling
- `cafe.js` - JavaScript
- `logo.png` and `manoushe.jpg` - images

## Run
Open `menu.html` in a browser. Keep the stylesheet, JavaScript file, and images in the same directory.

## About
This is a front-end class project and a café concept demonstration. It does not process actual orders or payments.
